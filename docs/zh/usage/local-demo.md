# 本地数字人演示版

本分支面向单机演示，提供「实时对话」「视频创作」「作品库」及[知识与记忆](knowledge-memory.md)工作流。

## 实时对话

选择形象与音色，点击「开始对话」。支持文字输入、麦克风语音、音频上传、流式回复、字幕、WebRTC 播放、打断和浏览器录制。

- 真人驱动：本地 QuickTalk。
- 备用：DOGO 轻量动画，使用浏览器渲染。
- 语言模型：已配置的 OpenAI 兼容远端 API。
- 语音识别：百炼 DashScope。
- 语音合成：Edge、百炼 Qwen，或百炼 Qwen-Audio 专属声音。

首次选择真人形象时会准备缓存。进行视频创作前应先结束实时会话，以免同时占用 GPU。

已连接时，顶部「结束对话」可断开当前会话、停止麦克风和播放并返回待启动状态，聊天记录保留。正在进行的录制会停止并自动保存到作品库。

DOGO 录制保留浏览器中的动画，请在动画准备完成后开始录制。

## 专属声音

在实时对话左侧「语音合成 → 专属声音」点击「克隆声音」，填写名称并上传录音。推荐 10～20 秒的单人清晰朗读，无背景音乐；支持 WAV、MP3、M4A、WebM、OGG、MP4，最大 10 MB，时长为 5～60 秒。

先在运行配置中保存北京地域的百炼语音 API Key。优先使用提供 100 万 Token 试用额度的 `qwen-audio-3.1-tts-flash`，实际剩余额度及有效期以账户为准。成功后自动保存并选用，支持试听和删除。所选声音同时用于实时对话和视频创作文案配音，刷新后保留。结束当前对话后再切换声音。

创建音色免费，试听和语音合成消耗百炼额度。是否有免费额度及有效期以百炼控制台为准。录音经临时转码后直接发送百炼，不提供公网下载地址；本地 SQLite 仅保存名称、音色 ID 与绑定模型。删除会同时删除百炼音色及本地记录。

## 视频创作

选择可用形象，上传音频或输入口播文案，生成带声音的短视频。支持进度查询、停止、预览和下载，生成成功后自动保存到作品库。生成期间应等待完成或先停止，再切换工作流。

## 作品库

查看实时录制与生成的视频，支持预览、分类筛选、分页、下载和删除。删除会确认，已有历史作品保留。

## 启动

在安装了依赖与 QuickTalk 权重的环境中执行：

```bash
bash scripts/start_unified.sh --backend local --model quicktalk --api-port 8210 --web-port 5173
```

打开 <http://localhost:5173>。通过右上角设置配置语言模型和百炼语音密钥；Edge 无需密钥。LLM 和百炼依赖网络及相应服务权限。

此机器已经配置的运行环境位于 WSL 的 `opentalking-workspace/opentalking`。Windows 源码改动需同步到运行副本，再重新构建前端并重启后端。

目录整理后的工作台在 `frontend/`，Python 应用、引擎与配置在 `backend/`，部署资源在 `deploy/`。根目录安装命令为 `pip install -e './backend[dev]'`；前端从 `frontend/` 执行 `npm ci`。也可直接在安装好依赖的当前仓库启动，无需覆盖已有 WSL 运行副本。详见[项目目录与开发](../docs/project-layout.md)。

## 删除范围

界面和 API 已移除视频克隆、推流、知识库、长期记忆、微信记忆导入、角色包和占位模块。驱动模型只注册 QuickTalk 与 mock；前端只提供已部署的语音服务。

现有形象、权重、密钥与作品不清空。QuickTalk 仍依赖共用的会话、音视频、渲染和任务代码，部分内部文件沿用历史模型名称，不代表继续提供对应产品功能。

仓库中其他多模型部署文档记录上游实现背景，不代表本演示版开放的功能。
